# Портфолио: как добавить фото и выложить на GitHub

## Что лежит в папке

```
site/
├── index.html      ← весь сайт (стили, анимации, тексты)
├── images/         ← сюда фотографии и скриншоты
└── videos/         ← сюда ролики mp4
```

Сайт сам подхватывает файлы. Положи фото с нужным именем в `images/`, и оно встанет на своё место.
Пока файла нет, на этом месте видна полосатая заглушка с именем файла.

## Какие файлы нужны

| Где на сайте | Имя файла | Формат |
|---|---|---|
| Полароид на папке (первый экран) | `images/hero.jpg` | вертикальное 4:5 |
| Фото рядом с содержанием | `images/content.jpg` | вертикальное 4:5 |
| Коллаж с фотополосками в «Обо мне» | `images/about-me.jpg` | квадратный или близкий к квадрату |
| Кейс 01 Sunscrypt, скриншоты | `images/case1-1.jpg`, `case1-2.jpg` | горизонтальные |
| Кейс 02 Психология, скриншоты | `images/case2-1.jpg` … `case2-3.jpg` | любые |
| Кейс 03 Café, марки-фото (7 шт.) | `images/cafe-1.jpg` … `cafe-7.jpg` | любые |
| Кейс 03 Café, ролики в айфонах | `videos/cafe-reel-1.mp4` … `cafe-reel-5.mp4` | вертикальные 9:16 |
| AI Production | `videos/ai-1.mp4`, `videos/ai-2.mp4`, обложки `images/ai-1-poster.jpg` и `images/ai-2-poster.jpg` | горизонтальные 16:9 |
| Презентации (9 и 7 слайдов) | `images/pres-1-1.jpg` … `pres-1-9.jpg`, `images/pres-2-1.jpg` … `pres-2-7.jpg` | горизонтальные |
| Чашка рядом с чеком и булочка в кейсе Café | `images/cv-latte.jpg`, `images/cafe-pastry.jpg` | квадратные |
| Бабочка в «Обо мне» | `images/butterfly.jpg` | квадратное |
| MacBook и конверты в «Контактах» | `images/contact-macbook.webp`, `images/contact-letter.jpg` | WebP с прозрачностью и квадратный JPG |
| Видео с приготовлением айс-латте в «Моём методе» | `videos/recipe.webm`, `videos/recipe.mp4` и `images/recipe-poster.png` | вертикальное 9:16 |

Шахматы (`chess-1.jpg` … `chess-5.jpg`) уже лежат в `images/`.

В разделе «Сайты» портфолио открывается в прокручиваемой рамке. Кнопка «Открыть» ведёт на полную страницу.

Видео в «Моём методе» перематывается при прокрутке. Версия WebM и обложка PNG сохраняют прозрачность. Версия MP4 для WebKit использует цвет фона секции `#f2ebe3`. При замене ролика обнови оба видео, обложку и время начала трёх последних шагов в массиве `cuts` в `index.html`. Короткие интервалы между ключевыми кадрами ускоряют перемотку.

**Важно:** имена без пробелов и русских букв, расширение `.jpg` маленькими буквами.
Фото лучше уменьшить до 2000 px по длинной стороне, а видео сжать до 5–10 МБ, иначе сайт будет грузиться медленно.

**Telegram:** в `index.html` найди строку `Telegram ↗` и замени `href="#"` на `href="https://t.me/твой_ник"`.

## Как посмотреть сайт у себя

Двойной клик по `index.html` откроет его в браузере.
Видео и некоторые эффекты надёжнее работают через маленький сервер. В Терминале выполни:

```bash
cd ~/Documents/Екатерина/site
```

```bash
python3 -m http.server 8000
```

Потом открой в браузере `http://localhost:8000`.

## Как выложить на GitHub Pages (бесплатно)

1. Зарегистрируйся на github.com. Твой ник станет адресом сайта, например `khudoyarova` → `khudoyarova.github.io`.
2. Нажми **New repository** (зелёная кнопка или «+» справа сверху).
   - Repository name: `ТВОЙ_НИК.github.io`. Тогда сайт будет открываться по короткому адресу.
   - Поставь **Public** и нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file**.
4. Открой папку `site` и перетащи в окно браузера **содержимое** папки: `index.html`, `images` и `videos`. Саму папку `site` перетаскивать не надо.
5. Внизу нажми **Commit changes**.
6. Зайди в **Settings → Pages**. В разделе *Build and deployment* выбери Source: **Deploy from a branch**, Branch: **main**, папка **/(root)**, затем **Save**.
7. Через 1–2 минуты сайт заработает по адресу `https://ТВОЙ_НИК.github.io`.

Чтобы обновить сайт, снова нажми **Add file → Upload files** и перетащи изменённые файлы. Одинаковые имена заменятся сами.

Ограничения GitHub: один файл не больше 100 МБ, через браузер можно загружать до 25 МБ за раз. Большие видео сжимай.

## Что внутри (анимации)

- Прелоадер: стакан айс-латте наполняется от 0 до 100.
- Первый экран: папка собирается слоями, имя пишется от руки, полароид падает на скрепку и покачивается. Папка следит за мышкой.
- «Мой метод»: стакан айс-латте собирается при прокрутке. Сначала падает лёд, потом льётся молоко, затем эспрессо расходится мрамором, и в конце защёлкивается крышка. Четыре шага = четыре части работы.
- CV: чек «Order Details» печатается, рядом плавно поворачивается чашка латте, на экране фотоаппарата появляются инструменты.
- Контакты: из-за крышки MacBook цвета шампанского по очереди вылетают коричневые конверты.
- Между разделами льётся кофе и заливает тёмный фон.
- Цифры считаются, полоски подписчиков растут, воронка рисуется стрелками.
- Café: фото вылетают из чашки латте, айфоны раскладываются веером.
- Шахматы: ноутбук со слайдами, автопрокрутка, свайп на телефоне.
- В правом нижнем углу чашка латте с кольцом прогресса прокрутки. Клик по ней возвращает наверх.
- Плавный скролл, свой курсор, магнитные кнопки, бегущая строка ускоряется от прокрутки.
- Если в системе включено «уменьшить движение», анимации отключаются.
